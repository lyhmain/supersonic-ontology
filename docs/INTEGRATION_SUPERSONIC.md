# SuperSonic 集成指南

本服务可独立使用(`/api/nl`),也可作为 SuperSonic 的旁挂插件,让聊天机器人获得
全部问数/分析能力。两种形态可并存(推荐:分析类问题走本服务,简单取数可保留
SuperSonic 原生 NL2SQL 快车道)。

## 前置

- SuperSonic ≥ 1.0(社区版),已有一个可用数据集(任一)
- 本服务已部署并可访问:`curl http://<host>:9102/api/health`

## 步骤

### 1. 建插件(管理员 → 插件管理)

- 名称:`决策分析`
- 参数:无需定义参数(问题通过 queryText 传递)
- 类型:WebService
- URL:`http://<本服务IP>:9102/api/plugin/analyze?queryText=(预置参数 queryText)`
  - 注意:容器部署时**不要写 127.0.0.1**,写宿主机/局域网 IP
- 指标/维度模式:全选或按需

### 2. 建 Agent

- 新建 Agent,工具只勾选上述插件(纯插件模式最稳)
- (可选)另建一个 Agent 勾选数据集,作为 SuperSonic 原生快车道

### 3. 聊天验证

| 问法 | 预期 data 文本 |
|---|---|
| 昨天<指标>是多少 | `<指标>合计 12,345.67` |
| 近30天各门店营业额 | `…合计…｜Top3: 门店A 1,234.00;… 等12组` |
| GMV超过5万的服务区有哪些 | 分组/HAVING 结果 |
| 9月GMV环比8月变化率是多少 | `环比 -16.64%,同比 …%` |
| 昨天营业额为什么下滑 | 归因+LLM 洞察(走 Jev 后端) |

## 契约细节

- 请求:`POST <url>?queryText=<用户问题>`,body 为参数键值(忽略)
- 响应:`{"columns": [...], "resultList": [...], "data": "<文本>"}`,SuperSonic 聊天
  界面展示 `data` 文本;分组结果的 Top3 明细会拼进 `data`
- 指定公司本体:`<url>&profile=<name>`(插件 URL 里直接带)
- 必须提供 `chatId`(SuperSonic 聊天自动带)

## 常见坑

| 现象 | 原因 |
|---|---|
| 插件测试通、聊天无反应 | Agent 工具未勾选插件 / 缺 queryText 预置参数 |
| 容器内连不上本服务 | URL 用了 127.0.0.1 |
| 聊天只回"合计"无明细 | 升级到含 Top3 拼接的版本(≥0.1.0) |
